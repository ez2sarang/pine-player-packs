"다음 곡", "좋아요", "이 곡 플레이리스트에서 빼줘" 처럼 말하면 대신 눌러 줍니다.

개인정보처리방침 플레이어 팩 저장소 팩 카탈로그 (JSON)

플레이어 팩이란

파인 플레이어가 새 음악 앱을 다루는 법을 적어 둔 설정값(JSON)입니다. 실행 코드는 들어 있지 않고, 앱은 이 값만 읽습니다. 앱 설정의 "팩 받기"에서 목록을 보고 고르면 기기에 저장되고, 같은 화면에서 지울 수 있습니다.

  • 팩 하나가 파일 하나입니다: packs/<id>.json
  • catalog.json 이 팩 목록이며, 항목마다 주소와 sha256 해시가 있습니다.
  • 앱은 HTTPS로 받아 해시가 맞을 때만 설치합니다.
